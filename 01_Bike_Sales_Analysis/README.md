# Bike Sales Analysis

## Project Overview
This project explores bicycle sales data to practise data analytics skills using Microsoft Excel.

## Objectives
- Understand the structure of a sales dataset.
- Prepare and clean data for analysis.
- Use sorting and filtering to explore sales information.
- Apply Excel formulas and calculations.
- Summarise data to identify purchasing patterns.

## Tools
- Microsoft Excel
- GitHub

## Project Status
In progress. The dataset, analysis, results, and findings will be added as the project develops.
