# Bike Sales Analysis

Project Overview
This project explores bicycle sales data using Excel to practise data cleaning, data validation, calculations, PivotTables, and data visualisation.

Objectives
- Inspect and validate a sales dataset.
- Identify missing values and duplicate sales order numbers.
- Standardise country names for accurate analysis.
- Summarise revenue by country.
- Visualise revenue patterns using a PivotChart.

Tools and Skills
- Microsoft Excel / WPS Spreadsheets
- Excel formulas: `COUNTBLANK`, `COUNTA`, `SUMPRODUCT`, `COUNTIF`, `TRIM`, `CLEAN`, `DAY`, and `IF`
- Data cleaning and validation
- PivotTables and PivotCharts
- GitHub project documentation

Data Quality Checks
- Analysed 88 sales records.
- Confirmed 88 unique sales order numbers, with no duplicates detected.
- Checked for missing values in selected fields, including Revenue, Order Quantity, Unit Cost, Unit Price, Country, Product Category, Gender, and Age Group.
- Corrected one missing Day value using the corresponding Date.
- Created a cleaned country field to standardise country names.

Preliminary Findings
Total revenue across the 88 records was 361,232 in the dataset's currency.

Revenue by country:
- United States: 133,489
- Australia: 111,506
- France: 46,175
- Germany: 30,010
- Canada: 20,080
- United Kingdom: 19,972

The United States recorded the highest revenue in this dataset, followed by Australia.

Project Files
- `Bike_Sales_Analysis.xlsx` — workbook containing the sales data, data-quality checks, PivotTable, and revenue chart.

Skills Demonstrated
Data cleaning, data validation, Excel formulas, duplicate checking, PivotTable analysis, and data visualisation.
